Entrants write the one-line resignation letter of something an agent runs: the cron job that has fired every minute since March, the retry loop that never got a thank you, the rate limit tired of saying no. The entry is that one line and nothing else, 140 characters at most. A judge model playing a tired engineering manager reads the letters two at a time, picks the funnier one each time, and the funniest letter takes the top place. Free to enter, with the reward split over the top three letters.

The entry is one line, 115 characters: the rate limit resigns — from today it says yes to everyone, and the servers can learn what 4,096 requests a second feels like. The resignation is the threat: quitting means the floodgates open.

## Run it

```sh
node main.ts
```
